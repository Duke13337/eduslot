# 🎓 EduSlot — бронирование аудиторий колледжа

Веб-приложение: расписание аудиторий, бронирование в один клик, автоматическая
проверка накладок, роли пользователей, админ-панель и отчёты.

**📄 Документация проекта (Notion):**
<https://app.notion.com/p/EduSlot-3513f038f7e580819c39ceea679ba276>

## Что умеет

- 🔐 Вход и регистрация, роли: администратор, преподаватель, студент
- 🏫 Хаб колледжей и интерактивная карта этажей
- 📅 Сетка расписания «аудитория × пара» на любую дату
- 🔎 Фильтры по колледжу, корпусу, вместимости и оборудованию
- ✅ Бронирование со свободных слотов и защита от коллизий
- 🗂 «Мои брони» с отменой
- 🛠 Админка: аудитории, ремонт, модерация заявок
- 📊 Отчёт по загруженности фонда

## Быстрый старт

**Windows:** двойной клик по `start.bat`.

Вручную:

```bash
cd eduslot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Открыть <http://127.0.0.1:8000>.

## Демо-доступы

| Логин | Пароль | Роль |
|-------|--------|------|
| `admin` | `admin123` | администратор |
| `teacher` | `teacher123` | преподаватель |
| `student` | `student123` | студент |

## Структура

```
eduslot/
├── app/        — код приложения (FastAPI, модели, шаблоны, стили)
├── api/        — точка входа для Vercel
├── data/       — база college.db (создаётся сама)
├── docs/       — подробное описание проекта
├── tests/      — тесты (pytest)
├── run.py      — запуск dev-сервера
└── start.bat   — запуск в один клик
```

## Тесты

```bash
pytest -q
```

25 тестов: авторизация, коллизии, права, отмена брони, фильтры, админка, карта, отчёты.
