## О проекте

EduSlot — веб-приложение для управления аудиторным фондом колледжа: поиск свободного
слота, электронная заявка, автоматическая проверка коллизий, подтверждение и отчётность.

Стек: Python 3.12, FastAPI, SQLModel, SQLite, Jinja2, pytest. Деплой — Vercel.

## Возможности

- **Роли**: администратор, преподаватель, студент (только просмотр).
- **Хаб колледжей**: список учебных заведений со статистикой и переходом к карте.
- **Карта этажей**: интерактивный план корпуса — аудитории расположены по координатам,
  показывают статус и число занятых пар, клик открывает расписание.
- **Расписание**: сетка «аудитория × учебная пара» на выбранную дату.
- **Фильтры**: колледж, корпус, минимальная вместимость, оборудование, поиск по номеру.
- **Бронирование**: занятые слоты недоступны, коллизии блокируются на сервере.
- **Мои брони**: активные заявки и история, отмена своей брони.
- **Админ-панель**: CRUD аудиторий с привязкой к колледжу, статус «доступна / на ремонте»,
  модерация заявок.
- **Отчёт**: загруженность каждой аудитории за период.

## Быстрый старт

```bash
cd eduslot
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python run.py
```

Приложение откроется на http://127.0.0.1:8000.

Альтернативный запуск:

```bash
uvicorn app.main:app --reload
```

## Демо-аккаунты

| Логин | Пароль | Роль |
|-------|--------|------|
| `admin` | `admin123` | администратор |
| `teacher` | `teacher123` | преподаватель |
| `student` | `student123` | студент |

База `data/college.db` создаётся и заполняется демо-данными при первом запуске
(отключается переменной `EDUSLOT_SEED=0`).

## Структура проекта

```

├── docs/                # документация проекта
```

## Тесты

```bash
pytest -q
```

Проверяются: авторизация, запрет бронирования для студентов, блокировка коллизий,
отмена брони и освобождение слота, фильтры (в т.ч. по колледжу), права администратора,
CRUD аудиторий, хаб колледжей и карта этажей, отчёт, а также соответствие публичного API
классов UML-диаграмме. Тестовая база создаётся во временной папке и не затрагивает рабочую.

|------------|------------|--------------|
| `EDUSLOT_DB` | путь к файлу SQLite | `data/college.db` |

## Деплой на Vercel

```bash
npm i -g vercel
vercel
```

Точка входа — `api/index.py`, конфигурация в `vercel.json`. Файловая система Vercel
доступна для записи только в `/tmp`, поэтому SQLite-база живёт до перезапуска функции.
Для постоянного хранения замените строку подключения в `app/database.py` на PostgreSQL
(например, Neon) — модели SQLModel от этого не меняются.

## Соответствие документации

| Раздел документа | Реализация |
|------------------|------------|
| Классы `User`, `Auditorium`, `Booking` | `app/models.py` + методы `login()`, `get_profile()`, `check_availability()`, `validate()`, `create()` |
| `ConflictChecker` | `app/services.py`, атрибуты `booking_data`, `db_session`, метод `check_collision()` |
| `RoomFilter` | `app/services.py`, атрибуты `search_params`, `filters_list`, метод `apply_filters()` |
| `AuthController` | `app/security.py`, атрибуты `secret_key`, `token_expire`, `algorithm`, метод `authenticate()` |
| `DatabaseManager` | `app/database.py`, атрибуты `db_url`, `engine`, `session_factory`, метод `get_session()` |
| «Хаб колледжей» | `/hub` → `hub.html` |
| Интерактивная карта | `/college/{id}` → `college_map.html` (план этажа) |
| Входные данные: логин, критерии поиска, параметры брони | формы `/login`, `/schedule`, `/book` |
| Выходные данные: сетка, результат операции, реестр, аналитика | `schedule.html`, flash-сообщения, `/my`, `/admin/report` |
| Проверка коллизий | `validate_booking()` + `ConflictChecker.check_collision()` |
| Роли и разграничение доступа | зависимости `require_user`, `require_admin` |

## Ограничения

- CSRF-защита не реализована (учебный проект, SameSite=Lax).
- Восстановление пароля и email-уведомления не входят в MVP.
- Одновременные записывающие операции сериализуются SQLite.
- Таблицы из Notion (точные строки «Таблицы классов» и тест-кейсов) не сверены дословно:
  Notion отдаёт их как коллекции, доступ к которым периодически блокируется Cloudflare.
